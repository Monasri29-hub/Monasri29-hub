### About Me

I'm a student who splits time between two things I love: solving algorithm problems on LeetCode (mostly in C++) and building visually striking, animated web experiences. I like projects that are technically rigorous *and* beautifully designed — from particle-system WebGL worlds to production Next.js sites with full custom animation systems.

- 🧠 Currently deepening **Dynamic Programming** and advanced algorithms
- 🎨 Currently building a **3D animated personal portfolio** (React Three Fiber, GSAP, Framer Motion, Next.js)
- 🏆 Stanford **Code in Place 2026** alum — shipped *CodeQuant*, an AI algorithm complexity analyzer
- 🤝 Open to creative-web and AI/ML collaborations
